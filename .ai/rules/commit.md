# Commit Conventions

## Commit message convention

- Use Conventional Commit format: `type: imperative lowercase subject`, with no period at the end.
- Allowed types: `feat`, `fix`, `chore`, `refactor`, `style`, `perf`, `test`, `docs`, and `ci`.
- An optional body should explain why the change is needed, not merely restate what changed.
- End every commit with this trailer:

    `Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>`
